{%- comment -%} Gathers what the pages need to know about one series. Usage: {% include series-info.html slug=SLUG %} It sets these for the page that included it: ser the series itself (empty if the name is not found) ser_parts its published pieces, in part order ser_total how many parts there will be (0 if nobody has said) ser_known true when the total is worth showing ("Part 2 of 3") ser_coming planned parts that are not published yet, in part order ser_fiction true when its first published piece is marked as fiction Only plain Liquid is used, so the GitHub Pages build can read it. {%- endcomment -%} {%- assign ser = nil -%} {%- for s in

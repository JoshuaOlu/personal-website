--- layout: default --- {%- comment -%} A short link: a page at a short address that sends people on to somewhere else. Link previews (LinkedIn, WhatsApp, Slack) read this page's head tags, so the preview can differ from the destination. People are then forwarded. Add and manage these in the _links folder (or in the console). See GUIDE.md, "Short links". Front matter used here: destination where to send people (must start with https:// or /) status live | paused | ended opens_on optional date (YYYY-MM-DD): before it, the link shows the "not open yet" message ends_on optional date (YYYY-MM-DD): the last day it works; after it, the link is closed after_end message (default) or forward (send people to fallback_url once closed) fallback_url where people can go instead, a page on this site or any address fallback_label words for that link, such as "read about the study" label what the destination is called, for "Taking you to ___" paused_message / ended_message your own wording for the two closed states pass_query true to keep ?extra=parts of the address when forwarding {%- endcomment -%} {%- assign dest = page.destination | strip -%} {%- assign dest_start = dest | slice: 0, 8 -%} {%- assign dest_first = dest | slice: 0, 1 -%} {%- if dest_start == "https://" or dest_first == "/" -%}{%- assign dest_ok = true -%}{%- else -%}{%- assign dest_ok = false -%}{%- endif -%} {%- assign today = site.time | date: "%Y-%m-%d" -%} {%- assign state = page.status | default: "live" -%} {%- if state == "live" and dest_ok == false -%}{%- assign state = "paused" -%}{%- endif -%} {%- if state == "live" and page.opens_on -%}{%- assign opens = page.opens_on | date: "%Y-%m-%d" -%}{%- if opens > today -%}{%- assign state = "paused" -%}{%- endif -%}{%- endif -%} {%- if state == "live" and page.ends_on -%}{%- assign ends = page.ends_on | date: "%Y-%m-%d" -%}{%- if ends < today -%}{%- assign state = "ended" -%}{%- endif -%}{%- endif -%} {%- assign label = page.label | default: "the link" -%} {%- assign fallback = page.fallback_url | default: "/" -%} {%- assign fallback_label = page.fallback_label | default: "go to the home page" -%} {%- if fallback contains "://" -%}{%- assign fallback_href = fallback -%}{%- else -%}{%- assign fallback_href = fallback | relative_url -%}{%- endif -%}
